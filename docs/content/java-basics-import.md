# Java Basics import

`JAVA BASICS UPDATED.docx` is the authoritative source for the canonical `java` course. Run `npm run convert:java-course` to regenerate the local course, its five versioned Firebase module files, Firestore metadata artifact, and extracted assets. Run `npm run validate:java-course` before publishing.

The course preserves five source chapters, 34 sections, 363 lessons, and 57 programming problems with their supplied solutions. Each exercise uses the shared compiler schema with a `Main.java` starter file, TeaVM program-mode configuration, source input, and normalized expected-output validation.

Three source quizzes do not include answer keys: `1.4.20`, `2.3.5`, and `5.1.9`. Their questions and options are preserved as lesson content rather than assigning invented answers. The remaining 43 quizzes are interactive.
