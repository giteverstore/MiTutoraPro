# Canonical Course image delivery

New Admin-authored Course image blocks use `{ id, type: 'image', assetId, alt, caption? }`. They do not store `src`, a signed URL, a bucket path, or image bytes. Existing published Course blocks with safe static `src` remain readable for backward compatibility and are not rewritten.

The existing Admin upload API validates PNG/JPEG/WebP data (2 MiB maximum), writes an immutable `admin-content-assets/asset-<uuid>.<extension>` object to the dedicated private Admin bucket, and creates `adminContentAssets/{assetId}` metadata plus an audit record. There is no bucket listing or public bucket permission. The draft stores only the returned `assetId` and its own alt/caption text. Admin Course Preview requests the metadata and then private bytes via authenticated `/api/admin-content/assets/{assetId}/file`; invalid references fail closed.

Before publication, the service checks that each asset-ID-only Course image has registered metadata and a readable, bounded object in the dedicated bucket. The published JSON keeps the stable `assetId`. The Admin public asset route accepts `/api/admin-content/public/assets/{contentId}/{version}/{assetId}` only when the requested READY Course version's verified artifact references that image. It reads the registered private object and serves only PNG/JPEG/WebP bytes. The learner client derives a same-origin, version-pinned URL when adapting the published Course, without adding that URL to the artifact. The existing learner Vercel `/api/admin-content/public/*` rewrite forwards the request to Admin Production. A rollback or pinned older version resolves assets against its own immutable artifact.

No signed URL is generated or serialized. The read is limited to 2 MiB and does not rely on an ACTIVE pointer, so previously READY versions remain usable. Preview deployments remain fail-closed. Admin Production requires the existing dedicated bucket; `https://admin.ycoders.com` is the canonical approved Admin public origin and must remain reachable. Do not publish a Course with private images until both Admin and learner route smoke tests pass.

The Practical Git and GitHub source draft still contains original static image paths as a local conversion artifact. Its eventual Admin import payload must replace each of the 15 image blocks' placeholder `assetId` with the corresponding ID returned by Admin upload and remove `src`. This does not change lesson text, ordering, alt text, or captions. No upload, import, validation, or publication occurs as part of this platform-support change.
